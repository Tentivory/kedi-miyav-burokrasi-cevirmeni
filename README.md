# Kedi Miyav Bürokrasi Çevirmeni

## Resmi Bildiri

Bu depo, evcil kedilerin sesli beyanlarını Türk idari yazışma geleneğine aktaran
uluslararası ölçekte tanınmayan fakat içeride çok önemli bir protokoldür.

Proje; mama kasesi krizlerini, kutu işgallerini ve lazer noktası
taarruzlarını resmi evrak haline getirmek üzere tasarlanmıştır.

## Neden Var?

Çünkü miyav tek başına hukuki sonuç doğurmaz.
Tebliğ doğurur. Belki.

## Kurulum

```bash
python3 cevirmen.py miyav
python3 cevirmen.py "miyav miyav"
python3 cevirmen.py mrr
```
